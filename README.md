# CrowdFunding-Analysis

# 📌 Overview

This project analyzes crowdfunding campaign data to identify success patterns, funding trends, category performance, and location-based insights using SQL, Excel, Power BI, and Tableau.

# 🛠 Tools Used

SQL (Data Cleaning & Aggregation)
Microsoft Excel (Preprocessing & KPI Analysis)
Power BI (Interactive Dashboard & DAX)
Tableau (Data Visualization & Storytelling)

# 📈 Key KPIs

Total Projects
Success Rate (%)
Average Days for Success
Total Amount Raised
Backers Count

# 📊 Dashboard Insights

Projects by Goal Range
Top 10 Successful Categories
Year-wise Project Trends (2009–2019)
Projects by Outcome (Successful, Failed, etc.)
Top 10 Locations by Projects
